04 Dify-style Output Workflow

기억 검색 결과가 Output 노드를 거쳐 대화방과 기록집으로 나뉩니다.

Dify의 Answer 노드처럼 바로 출력하지 않고, Dearlog는 초안, 편집 계획, 검수, 최종 PDF 단계를 거칩니다.

Output Canvas

Knowledge Retrieval → Generation Nodes → Review → Final Output

K
Memory Context
Knowledge Retrieval
MemoryChunk, RAG context, Photo context를 산출물 생성 노드에 전달합니다.
D
Digital Twin
Answer Node
기억 기반 대화방 응답과 근거 배지
G
Ghostwriter
Draft Node
챕터별 자서전 초안과 source chunk
C
Cover Agent
Design Node
표지 팔레트와 템플릿 추천
P
Publication Agent
Book Planning Node
편집 계획, 강한 장/약한 장, 사진 배치, 책 매니페스트를 만듭니다.
R
Family Review
Human Review
책 미리보기와 검수 탭에서 품질 체크, 추가 질문, 직접 인용 후보를 확인합니다.
E
Final Output
A5 PDF / Chat
가족 대화방과 최종 A5 기록집 PDF로 전달됩니다.
Dearlog의 Output은 Dify의 Answer 노드처럼 보이되, 실제 서비스에서는 가족 검수와 독자용 PDF 변환을 포함합니다.
