03 Dify-style Guard Workflow

AI 생성물이 가족에게 보이기 전, Guard 노드를 통과합니다.

Dearlog의 안전장치는 Dify 워크플로우의 조건/검증 노드처럼 원문, 출처, 권한, fallback을 순서대로 확인합니다.

Safety Gate Canvas

Raw Memory → Knowledge → Guard → Reader Output

S
부모님 원문
Start / Raw Input
raw transcript를 삭제하지 않고 품질관리의 기준으로 남깁니다.
A
Archivist
Structuring Node
clean text, tags, reliability, chapter hint가 있는 MemoryChunk로 정리합니다.
K
Knowledge Retrieval
RAG / Graph RAG
대화와 책 생성에 사용할 실제 기억 근거를 검색합니다.
IF
Safety Guard
Condition / Policy
출처 ID, 권한/동의, 금칙어, fallback 조건을 확인합니다.
E
Reader Output
End
가족이 보는 대화방/책/PDF에는 독자용 내용만 표시됩니다.
Dify의 조건 분기처럼, 근거가 부족하면 생성물이 바로 통과하지 않고 fallback 또는 추가 질문으로 이동합니다.
