# Dearlog Mobile Journey + Wireframes

This folder contains Figma import-ready design artifacts for the Dearlog mobile-first journey.

## Figma File

- URL: https://www.figma.com/design/gs0zqw3LWkLWRFoSrRt5Tm
- Current live status:
  - `00 Service Journey Map`: populated in Figma
  - `01 Mobile Wireframes`: populated in Figma
  - `02 Tablet Wireframes + 03 Components`: available in the SVG/HTML backup; Figma population was blocked by the Starter plan MCP call limit

## Files

- `dearlog-mobile-journey-wireframes.svg`: Main Figma-importable board.
- `dearlog-mobile-journey-wireframes.html`: Browser review version with the same board embedded.
- `generate-dearlog-wireflow.mjs`: Generator used to keep the SVG and HTML in sync.

## Figma Structure Represented

- `00 Service Journey Map`: Full journey from login/signup to settings.
- `01 Mobile Wireframes`: Smartphone `390x844` frames.
- `02 Tablet Wireframes`: Tablet `768x1024` frames.
- `03 Components`: Buttons, journey rail, cards, status chips, privacy selector.

## Import Notes

The live Figma file has native editable layers for the journey map and mobile wireframes. The SVG/HTML artifacts contain the complete planned board, including tablet wireframes and components.
Open Figma or drag `dearlog-mobile-journey-wireframes.svg` onto the canvas if you need the full board in one import.
