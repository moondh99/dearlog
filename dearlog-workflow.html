Dearlog의 에이전트 정의

Dify 워크플로우처럼 노드를 연결해, 가족 기록 제작 공정을 설명합니다.

Dearlog의 에이전트는 하나의 챗봇이 아니라 Start, Router, Agent, Knowledge, Guard, Output 노드가 연결된 가족 기록 제작 워크플로우로 이해하면 됩니다.

One Message

이 자료가 설명해야 하는 한 문장

Dearlog는 가족의 흩어진 입력을 Dify식 워크플로우 노드처럼 처리해 근거 있는 기억 데이터, 검수 가능한 기록집, 최종 A5 PDF를 생성합니다.

Service Pipeline

전체 흐름은 3단계로 이해하면 됩니다

1

기억을 끌어내는 입력

부모님 답변, 자녀 질문, 사진, 일정이 기록 소재가 됩니다.

  • Interviewer
  • Question Queue
  • Photo Agent
  • Calendar Trigger
2

근거 있는 기억으로 정리

원문을 보존하고, 기억 chunk로 구조화하고, 충돌과 불확실성을 표시합니다.

  • Archivist
  • Verification
  • RAG Index
  • Graph RAG
3

가족이 보는 산출물 생성

저장된 기억만 근거로 대화방, 자서전 초안, 검수 화면, 최종 PDF를 만듭니다.

  • Digital Twin
  • Ghostwriter
  • Cover Agent
  • Publication Agent
