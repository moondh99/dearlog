# Dearlog 캡스톤 발표 패키지

## 1. 시연 시나리오

발표 시간은 3~5분을 기준으로 잡는다. 시작 전 `설정 > 발표 데모`에서 `발표용 데이터 불러오기`를 누르고 `네트워크 없이 시연`이 켜져 있는지 확인한다.

| 순서 | 화면 | 보여줄 기능 | 발표 멘트 |
| --- | --- | --- | --- |
| 1 | 설정 / 발표 데모 | 사전 DB 준비, 발표 준비 상태 | 실제 인터뷰 데이터가 저장돼 있다는 가정으로 안정적인 사전 DB를 불러옵니다. |
| 2 | 말씀 나누기 | 기록 범위 안내, 자녀 준비형 대화 회상, 사진 단서 기반 AI 질문 | Dearlog는 어린시절, 가족, 일, 전환점, 가치관, 사진 속 생활사로 기록 범위를 나누고, 자녀가 올린 사진은 AI 인터뷰 질문으로 바꿉니다. |
| 3 | 추억 보관함 / 가족 공간 | 태그, 사진, 주간 가족 퀴즈, 월 구독 재방문 루프, 가족 질문, 민감정보 마스킹 | 저장된 기억은 주간 퀴즈, 가족 질문, 기념일 알림으로 다시 가족 대화에 돌아오고, GPS 같은 민감정보는 원본 좌표 대신 확인 상태로 표시합니다. |
| 4 | 나의 분신 | 저장된 기억 기반 챗봇 답변과 STT 원문 근거 | 챗봇은 없는 이야기를 만들지 않고, 답변 근거가 된 원문을 가족이 바로 확인할 수 있습니다. |
| 5 | 자서전 | 제작 단계, 책 사양, 문장별 출처 확인, A5 인쇄용 PDF | 최종 결과물은 PDF 교정본 확인 후 실물 책 주문 준비 상태로 이어집니다. |

## 2. 인쇄물 점검

시연 전 `자서전 > 사전 자서전 불러오기 > 인쇄용 PDF`를 눌러 실제 파일을 생성한다.

| 항목 | 확인 기준 |
| --- | --- |
| 제작 단계 | 기억 수집, 가족 검수, 문장별 출처 확인, PDF 교정본, 실물 책 주문 준비 흐름이 보인다. |
| 표지 | 제목, 저자명, 캡스톤 발표용 부제가 보인다. |
| 목차 | 24개 챕터가 순서대로 표시되고 50페이지 이상 책 분량으로 보인다. |
| 본문 | A5 기준으로 문장이 너무 빽빽하지 않다. |
| 사진/본문 구성 | 각 챕터에서 사진 카드와 본문을 함께 볼 수 있고, 부록 사진 페이지도 포함된다. |
| 개인정보 | GPS 원본 좌표가 직접 노출되지 않는다. |
| 가족 검수 | 가족 확인을 거친 인쇄물이라는 설명이 가능하다. |
| 책 사양 | A5 세로형, 대표 사진, 무선 제본 기준 같은 실물 책 사양을 설명할 수 있다. |

## 3. 데모 데이터 구성

- 어르신: 김영자, 1950년대생
- 기억 카드: 시장, 학교, 라디오, 서울역, 하숙집, 봉제공장, 결혼식, 육아, 전셋집, 장례식, 반찬가게, IMF, 병간호, 김장, 손녀, 스마트폰, 칠순, 코로나 영상통화, 가족 편지 등 24개
- 기록 범위: 어린시절과 학창시절, 가족과 관계, 일과 생계, 전환점과 감정, 가치관과 남길 말, 사진 속 생활사
- 사진: 부산 시장, 서울역, 가족 사진, 송도 바다, 국민학교, 라디오, 봉제공장, 하숙집, 결혼식, 첫아이, 도시락, 전셋집, 반찬가게, 김장, 스마트폰, 칠순, 영상통화 등 17장
- 실제 PNG 사진 샘플: 개인정보 보호를 위해 실존 인물이 아닌 AI 생성 가상 가족 사진 8장을 사용한다.
- 가족 일정: 손녀 생일, 가족사진 촬영 기념일
- 가족 질문: 서울 첫날, 손주에게 남길 말, 손녀와 나들이
- 챗봇 추천 질문:
  - 처음 서울에 올라왔을 때 이야기를 들려주세요
  - 어머니와 시장에 갔던 날은 어떤 기억인가요?
  - 가족에게 꼭 남기고 싶은 말씀이 있으신가요?
  - 첫 월급을 받았을 때 어떤 마음이었나요?

## 4. 발표 안전장치

- 발표 데모 탭의 준비 상태가 모두 완료인지 확인한다.
- 네트워크가 불안정해도 챗봇은 오프라인 데모 응답으로 동작한다.
- GPS 좌표는 앱과 인쇄물에서 직접 보여주지 않는다.
- 발표 전 `발표용 데이터 초기화` 후 다시 불러오면 동일한 상태로 복구할 수 있다.

## 발표 전 체크

- `npm run lint`, `npm test`, `npm run build` 통과
- 로컬 서버 실행 후 `/settings`에서 발표 데이터 준비
- 자서전 PDF 파일 생성 및 열람 확인
- 발표 질문 1개 이상을 직접 입력해 답변 근거 확인

## 8. PPT/포스터 핵심 문장

- 부모님의 기억을 AI 인터뷰로 수집하고 가족 기억 아카이브로 보존합니다.
- 여섯 가지 기록 범위로 질문을 좁혀 막연한 회상을 구체화합니다.
- 자녀가 올린 사진의 인물·장소·시기 단서를 AI 질문으로 바꿉니다.
- 자녀가 준비하고 부모님은 음성으로 답하는 저마찰 회상 흐름을 제공합니다.
- 주간 퀴즈, 가족 질문, 기념일 알림으로 월 구독 재방문 루프를 만듭니다.
- 사진, 가족 질문, 회상 인터뷰를 하나의 기억 카드로 정리합니다.
- 주간 가족 퀴즈로 저장된 기억을 자녀와 손주의 대화로 되돌립니다.
- 근거 없는 AI 답변이 아니라 STT 원문까지 확인 가능한 분신 대화를 제공합니다.
- 원치 않는 기억은 활용 중지하거나 완전히 삭제할 수 있습니다.
- 앱 속 기록을 실제 A5 인쇄 자서전으로 완성합니다.
- PDF 교정본 확인 후 실물 책 주문 준비까지 이어집니다.
- 동의, 공개 범위, 민감정보 마스킹을 기억마다 함께 관리합니다.

## 9. 발표 산출물 패키지

아래 파일은 `artifacts/capstone-demo/`에 보관된 기존 발표용 스냅샷이다.
이를 만들던 `npm run demo:assets`와 생성 스크립트는 레거시 화면 제거 과정에서 함께
