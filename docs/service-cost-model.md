# Dearlog 서비스 유지비 및 API 비용 추정

작성일: 2026-06-03  
목적: 50명 규모 파일럿/초기 상용 운영을 가정한 팀 공유용 비용 추정 및 비즈니스 모델 논의 자료

## 요약

50명 규모의 Dearlog 초기 운영에서는 서버 비용보다 AI/API 사용량, 전화/음성 사용량, 그리고 운영 인건비가 비용 변동의 핵심이다.

로컬 파일럿을 클라우드에 올리는 최소 프로덕션 구성은 월 `약 $40~90` 수준에서 시작할 수 있다. 안정 운영과 백업/모니터링을 포함하면 월 `약 $70~150`, 원화 기준 `약 10만~22만원` 정도를 기본 유지비로 잡는 것이 현실적이다.

AI/API 변동비는 사용 패턴에 따라 월 `약 $20~400+`까지 흔들릴 수 있다. 50명 규모의 보통 사용량 기준으로는 월 `약 $50~150`를 1차 가정으로 둔다.

따라서 50명 초기 운영의 기술 원가는 대략 월 `약 $100~250`, 원화 기준 `약 15만~38만원` 범위로 보는 것이 적절하다. 전화 인터뷰, 인쇄본 제작, 배송, 고객지원 인건비는 별도 원가로 취급해야 한다.

## 현재 모델 및 비용 경로

현재 `.env` 기준 모델 설정:

```env
FACTCHAT_CHAT_MODEL="gpt-5.5"
FACTCHAT_VISION_MODEL="gpt-5.5"
FACTCHAT_WRITING_MODEL="gpt-5.5"
```

용도별 비용 경로:

| 용도 | 현재 모델/서비스 | 과금 경로 |
|---|---|---|
| 일반 대화/질문 생성 | FactChat `gpt-5.5` | FactChat |
| 사진 분석/사진 기반 질문 생성 | FactChat `gpt-5.5` | FactChat |
| 표지 분석/표지 설정 | FactChat `gpt-5.5` | FactChat |
| 자서전 챕터 문장화 | FactChat `gpt-5.5` | FactChat |
| 서문/발문 생성 | FactChat `gpt-5.5` | FactChat |
| 최종 질문 다듬기/말투 반영 | FactChat `gpt-5.5` | FactChat |
| 임베딩/RAG | OpenAI `text-embedding-3-small` | OpenAI |
| 음성 전사 | OpenAI 전사 모델, 현재 기본 `whisper-1` | OpenAI |
| 실시간 음성 브리지 | OpenAI Realtime 계열 | OpenAI |
| 전화 연결 | Twilio Programmable Voice | Twilio |

확인 사항:

- FactChat Gateway는 현재 `/chat/completions` 계열은 동작한다.
- FactChat Gateway에서 `/embeddings`는 `404 Not Found`였다.
- FactChat Gateway에서 `/audio/transcriptions`는 `404 Not Found`였다.
- FactChat Gateway에서 Realtime WebSocket은 `403`이었다.
- 따라서 임베딩, 전사, 실시간 음성은 현재 FactChat으로 과금 전환하지 않는 것이 안전하다.

## 50명 운영 가정

이 문서에서는 50명을 `기록 대상 부모님/가족 기록 공간 50개`로 보수적으로 계산한다. 만약 실제로는 자녀와 부모를 합쳐 총 사용자 50명, 즉 기록 공간 25개라면 AI/API 비용은 대략 절반으로 줄어든다.

기본 사용량 가정:

| 항목 | 보통 사용 가정 |
|---|---:|
| 기록 대상 | 50명 |
| 1인당 답변 | 20~40개 |
| 1인당 사진 업로드 | 5~10장 |
| 1인당 음성 답변 | 30분 내외 |
| 1인당 자서전 생성 | 1~2회 |
| 월간 적극 사용 기간 | 파일럿/제작 기간 중심 |

## 서버 및 인프라 비용

| 항목 | 추천 구성 | 월 예상 |
|---|---|---:|
| 앱 서버 | AWS Lightsail 2GB~4GB 또는 유사 VPS | `$12~24` |
| 데이터베이스 | Supabase Pro/Postgres 또는 관리형 Postgres | `$25` |
| 파일 저장소 | 사진/음성/PDF 5~20GB | `$0~5` |
| 백업/스냅샷 | DB/파일 백업 | `$5~15` |
| 로그/모니터링 | Sentry, Logtail, Uptime monitor 등 | `$0~20` |
| 도메인/SSL/CDN | 도메인 연 비용, SSL/CDN | `$1~3` |
| 합계 | 최소 프로덕션 | `$40~90/월` |
| 합계 | 안정 운영 | `$70~150/월` |

AWS Lightsail은 Linux/Unix 기준 2GB 플랜 `$12/월`, 4GB 플랜 `$24/월` 구간이 초기 운영에 적합하다. Supabase Pro는 `$25/월`부터 시작하며 100,000 MAU, 8GB DB, 100GB 파일 저장소 등 초기 Dearlog에는 충분한 범위다.

## AI/API 변동비 추정

공개 단가 참고:

| 모델/서비스 | 공개 단가 기준 |
|---|---:|
| OpenAI `gpt-5.5` | input `$5/1M tokens`, output `$30/1M tokens` |
| OpenAI `text-embedding-3-small` | `$0.02/1M tokens` |
| OpenAI 전사 모델 | `gpt-4o-transcribe` 약 `$0.006/분`, `gpt-4o-mini-transcribe` 약 `$0.003/분` |
| OpenAI Realtime | 오디오 토큰 기반 또는 분당 모델별 단가 |

주의:

- FactChat 실제 청구 단가는 FactChat 계약/정산표를 확인해야 한다.
- 현재 FactChat `/models/` 응답에는 모델 ID와 소유자만 있고 가격 정보는 없다.
- 따라서 GPT 비용은 OpenAI 공개 단가를 기준으로 한 참고치이며, 실제 FactChat 청구 금액과 다를 수 있다.

월간 AI/API 비용 시나리오:

| 사용 패턴 | 설명 | 월 예상 |
|---|---|---:|
| 낮음 | 텍스트 위주, 사진 적음, 자서전 1회 생성 | `$20~60` |
| 보통 | 1인당 20~40개 답변, 사진 5~10장, 30분 음성 | `$50~150` |
| 높음 | 긴 음성, 사진 많음, 자서전 여러 번 재생성 | `$150~400+` |

비용을 크게 좌우하는 요소:

- `gpt-5.5` 출력 토큰량
- 자서전 문장화 및 PDF 재생성 횟수
- 사진 분석 횟수
- 음성 전사 분량
- 실시간 전화 인터뷰 사용 여부
- 자서전 PDF를 여러 번 재생성하는지 여부

## 전화, SMS, 알림 비용

Dearlog 코드에는 Twilio 연동 준비가 포함되어 있다. 실제 전화 인터뷰를 붙이면 다음 비용이 추가된다.

| 항목 | 비용 구조 |
|---|---|
| 전화 연결 | Twilio 통화 분당 과금 |
| 실시간 음성 AI | OpenAI Realtime 비용 |
| 음성 전사 | OpenAI 전사 비용 |
| SMS 인증/초대/알림 | Twilio SMS 건당 과금 |
| 전화번호 임대 | Twilio 번호 월 임대료 |

전화 인터뷰는 비즈니스 모델에서 별도 옵션으로 빼는 것이 안전하다. 예를 들어 `30분 전화 인터뷰 포함 패키지`처럼 시간 제한을 둬야 원가 통제가 된다.

## 권장 가격 모델

초기 Dearlog는 월 구독보다 `부모님 한 분의 자서전 완성 패키지`가 더 자연스럽다. 이유는 사용자가 매월 쓰는 도구라기보다, 가족 기록이라는 명확한 산출물을 구매하기 때문이다.

권장 패키지 초안:

| 상품 | 구성 | 가격 후보 |
|---|---|---:|
| Lite | 질문/답변 수집, 디지털 PDF 1회 | `49,000~79,000원` |
| Standard | 사진 질문, 자서전 문장화, PDF 수정 1~2회 | `99,000~149,000원` |
| Premium | 전화 인터뷰 30분, 문장 다듬기 강화, 인쇄 옵션 | `199,000~299,000원+` |
| 인쇄본 추가 | 제작/배송 실비 + 마진 | 별도 |

원가 관점:

- 50명 보통 사용 기준 기술 원가를 월 15만~38만원으로 보면, 1인당 기술 원가는 매우 낮다.
- 하지만 고객지원과 콘텐츠 품질 검수가 들어가면 인건비가 핵심 원가가 된다.
- 따라서 가격은 API 원가 기준이 아니라 `완성된 가족 자서전의 가치` 기준으로 잡는 것이 맞다.

## 운영상 비용 절감 포인트

1. 일반 질문 생성은 `gpt-5.5`보다 저렴한 모델로 낮추는 옵션을 유지한다.
2. 자서전 최종 문장화도 현재는 `gpt-5.5`로 통일해 Claude Opus 4.8 고비용 사용을 피한다.
3. 사진 분석은 업로드 즉시 전체 분석하지 말고, 자녀가 후보 질문을 등록할 때만 확정 호출하는 방식으로 통제한다.
4. 자서전 PDF 재생성 횟수를 패키지별로 제한한다.
5. 음성 전사는 분 단위 원가가 있으므로 패키지별 포함 시간을 명시한다.
6. 실시간 전화 인터뷰는 고가 옵션으로 분리한다.
7. 임베딩은 매우 저렴하므로 비용보다 품질/개인정보/검색 정확도를 기준으로 판단한다.
8. 파일 저장은 원가가 낮지만, 백업과 삭제 정책을 명확히 둔다.

## 다음 확인 필요 사항

- FactChat의 `gpt-5.5` 실제 계약 단가
- FactChat이 향후 embeddings/audio/realtime 엔드포인트를 제공할 계획이 있는지
- Twilio 한국 발신/수신/번호 임대 실제 단가
- 인쇄본 제작 단가 및 배송비
- PG 수수료와 환불 정책
- 개인정보보호법 관점의 보관 기간, 삭제 요청, 가족 간 권한 관리 정책
